# نرم‌افزار مدیریت و نوبت‌دهی کلینیک زیبایی

این پروژه با Python، رابط گرافیکی Tkinter و پایگاه داده SQLite ساخته شده است. فایل راهنما داخل همین پوشه قرار دارد و با بازکردن پوشه پروژه در VS Code می‌توانید آن را از پنل Explorer باز کنید.

## ساختار پوشه‌ها

```text
clinic_beauty_project/
├── main.py                 # نقطه شروع اجرای برنامه
├── README.md               # همین راهنما
├── clinic.db               # هنگام اولین اجرا ساخته می‌شود
├── src/
│   ├── __init__.py
│   ├── config.py            # تنظیمات و مسیر پایگاه داده
│   ├── database.py          # ساخت و مدیریت SQLite
│   ├── repository.py        # پرس‌وجوها و دسترسی به داده‌ها
│   ├── services.py          # منطق برنامه و گزارش‌ها
│   └── gui.py               # پنجره‌ها و فرم‌های Tkinter
└── tests/
    └── test_clinic_app.py   # آزمون‌های خودکار
```

## پیش‌نیازها
- Python نسخه 3.10 یا جدیدتر
- Tkinter (در نصب معمول Python ویندوز وجود دارد)
- VS Code (اختیاری، برای ویرایش و اجرا)

هیچ کتابخانه ثالثی برای اجرای نسخه پایه لازم نیست.

## بازکردن پروژه در VS Code
1. فایل ZIP را از حالت فشرده خارج کنید.
2. در VS Code از منوی **File > Open Folder** پوشه `clinic_beauty_project` را انتخاب کنید.
3. از پنل سمت چپ **Explorer** فایل `README.md` را باز کنید. راهنما داخل خود VS Code نمایش داده می‌شود.
4. فایل `main.py` را برای مشاهده نقطه شروع برنامه باز کنید.

## اجرای برنامه
در VS Code از منوی **Terminal > New Terminal** ترمینال را باز کنید. مطمئن شوید مسیر ترمینال همان پوشه اصلی پروژه است؛ سپس اجرا کنید:

```bash
python main.py
```

در ویندوز اگر دستور بالا کار نکرد:

```powershell
py main.py
```

پایگاه داده `clinic.db` در پوشه اصلی پروژه ساخته می‌شود. این فایل حاوی اطلاعات است؛ برای حفظ اطلاعات آن را حذف نکنید. پیش از ارتقا یا جابه‌جایی پروژه از آن نسخه پشتیبان بگیرید.

## اجرای آزمون‌ها
از ترمینال، در پوشه اصلی پروژه اجرا کنید:

```bash
python -m unittest discover -s tests -v
```

## وظیفه هر بخش از کد
- `config.py`: تنظیم مسیر دیتابیس و قالب تاریخ و وضعیت نوبت‌ها.
- `database.py`: ساخت چهار جدول اصلی، فعال‌سازی کلیدهای خارجی و ارتقای ساختار دیتابیس قدیمی.
- `repository.py`: اجرای پرس‌وجوها و خواندن اطلاعات مشتریان، خدمات، نوبت‌ها و پرداخت‌ها.
- `services.py`: اعتبارسنجی داده‌ها، جلوگیری از تداخل زمانی، ثبت و ویرایش عملیات و محاسبه گزارش‌ها.
- `gui.py`: ساخت پنجره اصلی، تب‌ها، فرم‌ها، جدول‌ها و اتصال دکمه‌ها به منطق برنامه.
- `main.py`: اجرای برنامه و نمایش خطاهای سطح اجرا.

## امکانات
- مدیریت مشتریان: ثبت، ویرایش، حذف و جست‌وجو.
- مدیریت خدمات و تعرفه‌ها.
- ثبت و ویرایش نوبت و جلوگیری از تداخل زمانی.
- وضعیت‌های رزرو، انجام‌شده و لغوشده.
- نگهداری قیمت و مدت خدمت در لحظه ثبت نوبت تا تغییر تعرفه، سوابق قبلی را تغییر ندهد.
- ثبت چند پرداخت برای هر نوبت، ویرایش و حذف پرداخت و محاسبه مانده.
- داشبورد و گزارش دریافتی روزانه و ماهانه.

## نکات مهم
- تاریخ و ساعت نوبت با قالب میلادی `YYYY-MM-DD HH:MM` وارد می‌شود؛ نمونه: `2026-11-14 15:30`.
- مبالغ به تومان و به‌صورت عدد صحیح ثبت می‌شوند.
- حذف مشتری یا خدمتی که نوبت وابسته دارد، برای حفظ یکپارچگی اطلاعات مجاز نیست.
- گزارش درآمد، مجموع پرداخت‌های ثبت‌شده است و به معنی سود خالص نیست.
- برای استفاده واقعی در کلینیک، تهیه نسخه پشتیبان منظم و افزودن ورود کاربران و سطح دسترسی توصیه می‌شود.
